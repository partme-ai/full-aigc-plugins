# Craft 插件展示名称与官方图标

十三个本地候选统一使用 `xxCraft Use`。内部 plugin name、技能名与版本保持兼容。PrintCraft 标识对应展示名 PdfCraft Use。

Codex 及标准清单的 OpenAI 扩展使用包内 `interface.logo` / `logoDark`；ZCode 使用同款官方图标 URL。九个图标逐字节复用 ZCode 官方图标文件，四个取自 FigCraft、EffectCraft、FilmCraft、LightCraft 官方仓库的固定 commit；来源、摘要和图标许可证保留在各包 assets 目录。未改动编辑器本身的产品名称。
