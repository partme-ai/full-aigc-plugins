## Context

三个现有 MCP 插件已经提供标准配置；其余九个没有宿主 MCP 声明。中央市场的现有检查未强制这一条件。

## Goals / Non-Goals

目标：条件化要求标准配置，并为正式插件与可安装 RC 共用校验。

非目标：添加 MCP 服务、改动宿主配置、修复既有发布同步问题、运行供应商调用或发布插件。

## Decisions

- 将只读文件校验放入独立函数，便于使用临时目录验证缺失和无效配置。
- 从三个宿主 manifest 及根 `.mcp.json` 收集服务名。路径声明即表示使用 MCP；对象声明以非空服务集合为准。
- 检查标准文件结构、服务字段和包路径；聚合错误接入现有市场检查。
- 不安装校验依赖，不将检查称为完整 Schema 或运行时认证。

## Risks / Trade-offs

服务名称一致性是本项目附加治理要求；不同传输配置仍可保留宿主适配差异。无声明的脚本实现不能仅凭文件名认定已经启用 MCP。

## Migration Plan

现有插件无需改动。先添加失败测试，再实现校验并接入市场检查，最后核对全部 12 个插件。
