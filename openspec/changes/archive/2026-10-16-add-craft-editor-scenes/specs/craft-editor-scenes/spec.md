## ADDED Requirements

### Requirement: 内嵌编辑与同会话工具
插件 SHALL 提供真实 Craft 编辑器界面，Agent 的编辑工具与界面 MUST 操作同一会话。

#### Scenario: 宿主浏览器接入
- **WHEN** 宿主可打开网页但未呈现本地 MCP Apps
- **THEN** 插件返回本地桥接页面，页面连接当前编辑器服务，工具编辑可在页面观察。

#### Scenario: 缺失资源
- **WHEN** 编辑器制品缺失或摘要不匹配
- **THEN** 返回可诊断错误，不返回伪造的成功页面。

### Requirement: 工作区交付
插件 SHALL 在用户指定工作区打开文件并交付可编辑工程与派生输出。

#### Scenario: 实际保存
- **WHEN** 场景要求保存并导出
- **THEN** 检查实际输出存在并可重新打开，不以工具调用无异常代替交付。

### Requirement: 场景技能
技能 SHALL 包含领域决策、可执行步骤和结果检查，并以当前运行时能力为界。

#### Scenario: 老照片修复
- **WHEN** 用户请求修复老照片
- **THEN** 先诊断划痕、褪色及缺损，局部试修后逐区处理，保留人物特征，并交付源工程和对比输出；缺失的生成式重建能力明确说明。

### Requirement: stdio 与最新编辑器回退
宿主与插件 MCP SHALL 使用 stdio。首次打开编辑器 SHALL 尝试获取配置的维护方发行源中的最新兼容完整编辑器包，下载或校验失败 MUST 使用包内编辑器，不能破坏内置资源或当前工程。

#### Scenario: 最新版本可用
- **WHEN** 对应发行索引可用且最新包摘要、结构和工具接口检查通过
- **THEN** 在独立缓存目录使用该版本，状态返回来源及版本；不只替换 WASM 而混用不同版本的 JS。

#### Scenario: 下载失败或不兼容
- **WHEN** 网络超时、下载失败、摘要不符、压缩包异常或工具接口不兼容
- **THEN** 使用内置版本并报告回退原因，MCP 不因更新失败而退出。

#### Scenario: 活动会话
- **WHEN** 编辑器已打开或已执行编辑工具
- **THEN** 当前进程保持选定版本，后续打开不重新下载和切换；离线配置可直接选择内置版本。

### Requirement: 每工具独立插件与源码增强发行
十三种独立 Craft 工具（包含 FigCraft，PrintCraft 与 PdfCraft 为同一产品别名）SHALL 各有独立插件。按用户 2026-10-16 选择，缺少 Web 命令接口的应用 SHALL 参考 ZCode 模式，从用户 fork 的锁定源码加入自动化桥接并构建增强 WASM；暂缺 fork 的工具使用锁定上游源码并标记来源。已有公开 Web API 的应用可直接使用官方 Web Release。更新优先自有兼容增强发行包，下载失败回退已验证内置版本；原版 Web 不得替换需要增强接口的 WASM。ZCode 作为接口与构建参考，保留许可证和修改归属，不作为后续资源更新权威。

#### Scenario: 多宿主内打开
- **WHEN** 宿主支持 MCP Apps 或内置浏览器
- **THEN** 插件通过该能力打开实际编辑器并共享命令会话；宿主不支持此能力时明确报告限制，不把外部浏览器称为宿主内打开。

#### Scenario: FigCraft
- **WHEN** 用户安装 FigCraft Use
- **THEN** 可发现其独立 stdio MCP、官方图标、编辑器入口与界面设计场景技能，并可保存工作区工程。
