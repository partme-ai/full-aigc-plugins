# 安全策略

> 2026-10-09；以下是设计与贡献约束，尚无运行时强制实现。

本项目处理的敏感数据包括演示内容、备注、嵌入媒体、文件路径和截图。只读取任务所需范围；不得把内容上传外部模型或服务，除非用户授权该用途及数据范围。
文件操作校验规范化路径、符号链接与授权目录；覆盖和破坏性操作必须检查现有授权是否覆盖具体目标。普通已授权创建与编辑不重复请求许可。
DeckCraft 本机控制端口不是权限边界：仅监听 loopback 也不能证明调用者身份可信。不要把端口暴露到局域网或公网。
导入 PPTX、图片和视频是非可信输入；限制压缩展开、尺寸、像素、运行时间、日志和媒体解码资源。硬限制不依赖模型判断。
进程参数、错误、状态和回执不得保存秘密；将文稿与截图写入受限工作目录，保留时间由任务要求确定，不假定加密已经实现。

## 报告与响应

尚无公开安全邮箱或漏洞门户。发现问题时在当前项目协作会话提供脱敏复现，保留原状态与输入摘要，不公开私人文稿和凭据。未来发布前建立私密报告渠道、支持版本范围及补丁流程。
