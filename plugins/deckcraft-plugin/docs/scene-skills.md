# 场景技能候选

新增技能位于 skills/，独立技能源维护，插件本地候选按 scenario-candidates.json 校验。既有发布快照不变。当前完成内容与实际场景视觉验收分开；尚未逐场景完成用户素材验收。

- `deckcraft-pitch-deck`：项目路演（问题、方案、证据与诉求）
- `deckcraft-weekly-report`：周报演示（进展、问题、指标与下周计划）
- `deckcraft-training-slides`：培训课件（讲解、示例、练习与回顾）
- `deckcraft-data-story`：数据叙事演示（数据结论与业务解释）
- `deckcraft-brand-template`：品牌演示模板（母版风格与常用版式）
- `deckcraft-slide-redesign`：演示文稿重排（旧稿结构与视觉优化）
