# 使用与故障排查

> 2026-10-09。当前已有本地候选包；以下是加载验证顺序，尚无远端发行或已验证宿主。

1. 检查安装包根目录包含合法 `plugin.json`，并核对可选 `skills/`、`mcp.json` 的实际路径仍位于包内。
2. 确认目标客户端支持所用 Agent Plugins 版本及 MCP stdio，且用户已安装可定位的 `deckcraft-cli`。
3. 先验证 Skills 加载、MCP 握手与只读命令发现，再在授权范围内测试写入和导出。
4. 检查保存后的原生文稿、inspect 回读、渲染和导出重开；不同格式单独报告结果。

| 情况 | 下一步 |
|---|---|
| 没有 DeckCraft CLI | 只读诊断，安装须由已有任务授权覆盖 |
| 插件 manifest 无效 | 修正 `$schema`、`name` 或字段；无效时不能发现组件 |
| MCP 连接失败 | 报告进程/握手原因；合法 Skills 仍可加载 |
| Headless 无整窗截图 | 使用幻灯片渲染，或经单独验证的桌面 Remote |
| 修改请求回复丢失 | 回读文稿、报告不确定性，避免盲目重发 |
| PPTX 或导出差异 | 保留原件与结果，说明丢失内容和格式边界 |

卸载应保留用户文稿。当前没有插件状态目录、迁移脚本或独立预算存储。[兼容性](compatibility.md)、[验证矩阵](verification.md)。
