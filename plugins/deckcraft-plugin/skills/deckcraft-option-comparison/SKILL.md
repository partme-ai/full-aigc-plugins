# 方案评审对比表

本技能将已有操作手册的 `option-comparison-table` 深化为独立入口，补充真实ID绑定、宽度检查和PPTX回读，不计作新的独立场景。

1. 从输入确认方案名、比较维度、单位、期间和来源日期。不知道的值写“待核实”，不得填零或编造评分。先与用户已给定的标准对齐，再决定是否需要推荐结论。
2. 读取 [方法、ID与参数](references/craft-methods.md) 和 [逐步模板](references/craft-steps.json)。示例数字仅用于结构验证，制作时逐格替换为实际事实。
3. 已有文稿先检查目标页；保留其他页。新任务才执行 `file.new`。以原生表格承载内容，不用截图或多个文本框冒充可编辑表格。
4. 创建后查询真正的表格ID；逐格写入内容，再配置表头、行带与列宽。所有宽度单位为pt；变更一列可能改变总宽，必须检查列宽之和及右边界。
5. 给这一页添加讲者备注，说明数据来源与假设；正文表达比较结果，备注补充口径。没有共同标准时保持客观比较，不自动判定胜者。
6. 另存 `.deckcraft` 与 `.pptx`，重开检查表格、备注和文字。再在副本修改一个单元格并导出，确认它仍为原生可编辑表格。检查实际整页渲染的溢出、对齐和字号。

需要内嵌编辑器时交给 **deckcraft-editor** 技能。独立安装：`npx skills add full-aigc-skills/deckcraft-skills --skill deckcraft-editor`。本技能随DeckCraft开发预发布提供；真实素材与其他宿主仍需分别验收。

示例限定4行3列。内容过长先精简或按维度拆页，续页重复表头；当前流程未验证自动分页、屏幕阅读器表头语义、外部PowerPoint排版和宿主画面同步，不以文件生成代替这些检查。
