# DeckCraft report 场景

默认从新建空文件执行。按实际输入替换示例，已有文件先定位目标；不要清空或全选已有文稿。组合演示场景只新建一次，后续跳过带newDocumentOnly标记的步骤。

## executive-metric-page：管理层一页指标简报

输入：提供三项指标的时间范围、口径、单位与来源。

| 操作目的 | 命令 | 参数例子 |
| --- | --- | --- |
| 1. 新建960×540点空演示文稿，仅在新建任务中使用 | `file.new` | `{"size":[960,540],"blank":true}` |
| 2. 建立空白版心 | `slide.new` | `{"layout":"blank"}` |
| 3. 插入指定版心位置的可编辑文本图形 | `shape.insert` | `{"preset":"roundRect","rect":[48,24,864,64],"text":"本月经营摘要"}` |
| 4. 只填充刚插入的当前图形 | `shape.fill` | `{"color":"#dce6f4"}` |
| 5. 插入指定版心位置的可编辑文本图形 | `shape.insert` | `{"preset":"roundRect","rect":[48,130,264,160],"text":"交付 12 项"}` |
| 6. 只填充刚插入的当前图形 | `shape.fill` | `{"color":"#e8f0fe"}` |
| 7. 插入指定版心位置的可编辑文本图形 | `shape.insert` | `{"preset":"roundRect","rect":[348,130,264,160],"text":"待核验 3 项"}` |
| 8. 只填充刚插入的当前图形 | `shape.fill` | `{"color":"#fff4d6"}` |
| 9. 插入指定版心位置的可编辑文本图形 | `shape.insert` | `{"preset":"roundRect","rect":[648,130,264,160],"text":"完成率 80%"}` |
| 10. 只填充刚插入的当前图形 | `shape.fill` | `{"color":"#e4f4e7"}` |
| 11. 备注保留数据口径，不把示例当真实业绩 | `slide.notes` | `{"text":"示例数据；正式交付替换为有来源的统计口径。"}` |

检查：版心内无溢出与遮挡；备注记录来源与待确认假设；保存源工程、导出PPTX后核对可编辑对象。

边界：不要用指标卡掩盖缺失分母或不同周期；示例值不构成实际经营结果。

## risk-quadrant：风险四象限汇报页

输入：概率与影响评级口径已确认；矩阵只是表达，不替代风险判断。

| 操作目的 | 命令 | 参数例子 |
| --- | --- | --- |
| 1. 新建960×540点空演示文稿，仅在新建任务中使用 | `file.new` | `{"size":[960,540],"blank":true}` |
| 2. 建立风险矩阵版心 | `slide.new` | `{"layout":"blank"}` |
| 3. 插入指定版心位置的可编辑文本图形 | `shape.insert` | `{"preset":"roundRect","rect":[48,24,864,60],"text":"影响 ↑ / 概率 →"}` |
| 4. 只填充刚插入的当前图形 | `shape.fill` | `{"color":"#dce6f4"}` |
| 5. 插入指定版心位置的可编辑文本图形 | `shape.insert` | `{"preset":"roundRect","rect":[160,110,300,150],"text":"低概率·高影响\n原件遗失：备份核验"}` |
| 6. 只填充刚插入的当前图形 | `shape.fill` | `{"color":"#fff4d6"}` |
| 7. 插入指定版心位置的可编辑文本图形 | `shape.insert` | `{"preset":"roundRect","rect":[480,110,300,150],"text":"高概率·高影响\n输入延期：逐项补齐"}` |
| 8. 只填充刚插入的当前图形 | `shape.fill` | `{"color":"#f8d7da"}` |
| 9. 插入指定版心位置的可编辑文本图形 | `shape.insert` | `{"preset":"roundRect","rect":[160,280,300,150],"text":"低概率·低影响\n编号笔误：二次校验"}` |
| 10. 只填充刚插入的当前图形 | `shape.fill` | `{"color":"#e4f4e7"}` |
| 11. 插入指定版心位置的可编辑文本图形 | `shape.insert` | `{"preset":"roundRect","rect":[480,280,300,150],"text":"高概率·低影响\n录入返工：模板约束"}` |
| 12. 只填充刚插入的当前图形 | `shape.fill` | `{"color":"#fff4d6"}` |
| 13. 记录风险评估依据与待补充事项 | `slide.notes` | `{"text":"先定概率与影响口径，再将真实风险放到对应象限；仅颜色不能表达全部风险。"}` |

检查：版心内无溢出与遮挡；备注记录来源与待确认假设；保存源工程、导出PPTX后核对可编辑对象。

边界：示例风险、概率影响口径、责任人与缓解措施必须替换为真实输入；颜色与位置不能替代风险判断。
