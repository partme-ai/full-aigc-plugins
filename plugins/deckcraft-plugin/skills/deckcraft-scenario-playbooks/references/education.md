# DeckCraft education 场景

默认从新建空文件执行。按实际输入替换示例，已有文件先定位目标；不要清空或全选已有文稿。组合演示场景只新建一次，后续跳过带newDocumentOnly标记的步骤。

## training-hidden-answer：培训问答与隐藏答案页

输入：问题与答案已由讲师确认，隐藏页不是保密机制。

| 操作目的 | 命令 | 参数例子 |
| --- | --- | --- |
| 1. 新建960×540点空演示文稿，仅在新建任务中使用 | `file.new` | `{"size":[960,540],"blank":true}` |
| 2. 建立按信息结构选择的标题内容页 | `slide.new` | `{"layout":"titleAndContent","title":"练习：如何处理重复编号","body":"A 直接删除；B 先核验来源与业务含义。"}` |
| 3. 将讲解要点放演讲者备注 | `slide.notes` | `{"text":"给学员30秒讨论后，再解释为什么选B。"}` |
| 4. 建立按信息结构选择的标题内容页 | `slide.new` | `{"layout":"titleAndContent","title":"答案与解析","body":"B：先核验，再依业务规则处理。"}` |
| 5. 默认放映隐藏答案，讲师按需进入 | `slide.hide` | `{"hidden":true}` |

检查：版心内无溢出与遮挡；备注记录来源与待确认假设；保存源工程、导出PPTX后核对可编辑对象。

边界：隐藏页仍包含在PPTX中，不用于存放敏感信息；正式播放前检查跳页方式。
