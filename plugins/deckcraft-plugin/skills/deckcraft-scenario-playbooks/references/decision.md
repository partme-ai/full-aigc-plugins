# DeckCraft decision 场景

默认从新建空文件执行。按实际输入替换示例，已有文件先定位目标；不要清空或全选已有文稿。组合演示场景只新建一次，后续跳过带newDocumentOnly标记的步骤。

## option-comparison-table：可编辑方案比较表

输入：提供相同维度的候选方案，禁止把不等口径数字直接并列。

| 操作目的 | 命令 | 参数例子 |
| --- | --- | --- |
| 1. 新建960×540点空演示文稿，仅在新建任务中使用 | `file.new` | `{"size":[960,540],"blank":true}` |
| 2. 建立按信息结构选择的标题内容页 | `slide.new` | `{"layout":"titleAndContent","title":"方案比较","body":""}` |
| 3. 建立3×3可编辑比较表 | `insert.table` | `{"rows":3,"cols":3,"rect":[48,130,864,280]}` |
| 4. 设置当前比较表的单元格文字 | `text.set` | `{"cell":[0,0],"text":"维度"}` |
| 5. 设置当前比较表的单元格文字 | `text.set` | `{"cell":[0,1],"text":"方案A"}` |
| 6. 设置当前比较表的单元格文字 | `text.set` | `{"cell":[0,2],"text":"方案B"}` |
| 7. 设置当前比较表的单元格文字 | `text.set` | `{"cell":[1,0],"text":"交付"}` |
| 8. 设置当前比较表的单元格文字 | `text.set` | `{"cell":[1,1],"text":"快速试点"}` |
| 9. 设置当前比较表的单元格文字 | `text.set` | `{"cell":[1,2],"text":"完整建设"}` |
| 10. 设置当前比较表的单元格文字 | `text.set` | `{"cell":[2,0],"text":"约束"}` |
| 11. 设置当前比较表的单元格文字 | `text.set` | `{"cell":[2,1],"text":"人工复核"}` |
| 12. 设置当前比较表的单元格文字 | `text.set` | `{"cell":[2,2],"text":"实施周期"}` |
| 13. 明确首行为表头 | `table.options` | `{"headerRow":true}` |
| 14. 补充比较结论适用条件 | `slide.notes` | `{"text":"比较依据：当前范围与资源。最终选择由决策人确认。"}` |

检查：版心内无溢出与遮挡；备注记录来源与待确认假设；保存源工程、导出PPTX后核对可编辑对象。

边界：此处不自动作商业决策；真实任务应补充来源与决策条件。
