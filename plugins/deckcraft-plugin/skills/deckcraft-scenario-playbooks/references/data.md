# DeckCraft data 场景

默认从新建空文件执行。按实际输入替换示例，已有文件先定位目标；不要清空或全选已有文稿。组合演示场景只新建一次，后续跳过带newDocumentOnly标记的步骤。

## trend-actual-plan：实际与计划趋势图

输入：相同周期、同单位的实际与计划数据，明确无数据月份。

| 操作目的 | 命令 | 参数例子 |
| --- | --- | --- |
| 1. 新建960×540点空演示文稿，仅在新建任务中使用 | `file.new` | `{"size":[960,540],"blank":true}` |
| 2. 建立按信息结构选择的标题内容页 | `slide.new` | `{"layout":"titleAndContent","title":"实际与计划","body":"单位：件；示例数据"}` |
| 3. 插入两序列可编辑折线图 | `insert.chart` | `{"type":"line","rect":[80,150,800,300],"categories":["一月","二月","三月"],"series":[{"name":"实际","values":[80,95,110]},{"name":"计划","values":[90,100,105]}]}` |
| 4. 设置图例和标题以分清两组数据 | `chart.options` | `{"title":"交付量趋势","legend":"b","dataLabels":true}` |
| 5. 注明来源与结论边界 | `slide.notes` | `{"text":"数据来源待替换；三个月趋势不支持全年预测。"}` |

检查：版心内无溢出与遮挡；备注记录来源与待确认假设；保存源工程、导出PPTX后核对可编辑对象。

边界：不能将缺失值填为零或把计划当实际；图表视觉检查轴与图例。
