# 贡献指南

当前为文档阶段。先阅读 [需求](docs/requirements.md)、[架构](docs/DeckCraft-Plugin-Architecture.zh_CN.md) 和 [验证矩阵](docs/verification.md)。

1. 修改前核实仓库根、分支和未提交文件；保护已有工作，不改研究来源。
2. 文档修改需同时维护中英文 README 的顺序、状态、命令、数量和链接。
3. 实现行为变更时先写可观察验收与失败回归，确认因目标缺陷失败，再实现并跑受影响检查。
4. 所有命令通过可信程序路径和 argv 参数调用，不能把用户内容拼接进 shell。
5. 单技能安装不得依赖未安装的兄弟技能；分发必须固定来源和摘要。
6. 记录源码 SHA、输入摘要、制品摘要和验证层；不能用历史报告证明新源码。
7. 提交、创建分支、安装、远端发布按当前会话授权执行，文档更新不自动授权这些动作。

当前没有项目 lint/test 脚本或 CI，不能声称已通过行为测试。文档可运行 `git diff --check`；新文件还需单独检查空白、链接和围栏。
尚未选定正式规格体系；本轮文档是实现输入，不是已批准的完整发布规格。首次体系初始化另行按项目规则执行。

新增运行组件前，先列出用户可见能力、现有宿主/DeckCraft/Skill 的归属、可复现缺口、最小实现与行为验收。无法满足的保证继续列为限制；不凭抽象的可靠性目标增加常驻控制器。
