# 按确认边界拆分发票包

先读取[具体方法、参数与边界](references/craft-methods.md)，再按[结构化步骤](references/craft-steps.json)执行。数值、文件名和标题是样例，必须按当前输入替换；不能把样例当实际业务事实。

## 输入与执行

用户提供了多页发票或单据包及各单据起始页，需要分别交付且不漏页。先核对输入文件、用户批准的修改范围和目标输出。边界表是已确认输入，不按空白页或数字金额猜单据边界。拆分不核实税务真实性、不判断报销合规；加密/签名文档先确认输出要求，输出使用新目录。

保持单一原生CLI脚本或同一MCP会话，使用当前doc_open实际返回ID。CLI编译器的文档槽只适用于其生成的全新进程脚本，不是已运行编辑器ID。工具缺失时报告缺口，不用相似命令冒充。

## 验证与交付

重开三份输出，分别2/1/3页；逐页标识顺序与原1-6页完全相同，不丢页、不跨单据；源PDF字节不变。

交付真实存在的新输出和简短处理说明，保留输入；若仅完成技术样本检查，明确未验证真实复杂文档或宿主内同步。无需其他兄弟技能资源；本技能内含全部必要引用与脚本。
