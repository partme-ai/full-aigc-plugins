# 场景技能候选

新增技能位于 skills/，独立技能源维护，插件本地候选按 scenario-candidates.json 校验。既有发布快照不变。当前完成内容与实际场景视觉验收分开；尚未逐场景完成用户素材验收。

- `printcraft-organize-pdf`：PDF 页面整理（合并、拆分、排序与旋转）
- `printcraft-ocr-scans`：扫描 PDF 识别（扫描文档 OCR 与可搜索输出）
- `printcraft-redact-pdf`：PDF 内容遮盖（敏感信息永久移除）
- `printcraft-compress-pdf`：PDF 体积优化（图片压缩与阅读质量平衡）
- `printcraft-fill-pdf-forms`：PDF 表单填写（表单字段、勾选项与输出）
- `printcraft-pdf-preflight`：PDF 交付检查（页框、字体、图像与打印前检查）
