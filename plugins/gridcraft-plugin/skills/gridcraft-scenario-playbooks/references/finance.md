## invoice-line-tax：报价明细、折扣与税额

输入：新建报价表；数量、单价、折扣与税率由任务提供，不内置现实税制。

| 操作目的 | 命令 | 参数例子 |
| --- | --- | --- |
| 1. 将真实业务记录按列结构写入；示例为可计算的测试输入 | `range.setValues` | `{"range":"A1","values":[["项目","数量","单价","折扣","未税金额","税率","税额","含税金额"],["服务A",2,100,0.1,"=B2*C2*(1-D2)",0.06,"=E2*F2","=E2+G2"],["服务B",1,50,0,"=B3*C3*(1-D3)",0.06,"=E3*F3","=E3+G3"],["合计",null,null,null,"=SUM(E2:E3)",null,"=SUM(G2:G3)","=SUM(H2:H3)"]]}` |
| 2. 对金额列设显示格式，不把金额转成字符串 | `home.numberFormat` | `{"range":"E2:H4","format":"0.00"}` |
| 3. 检查公式与原始数据位置 | `sheet.read` | `{"range":"A1:H4","formulas":true}` |
| 4. 读取未格式化计算值，按检查项核对结果及错误值 | `sheet.read` | `{"range":"A1:H4","formulas":false,"formatted":false}` |

检查：E4未税230，G4税额13.8，H4含税243.8；数量与单价仍为数值；税率与币种在交付中明确。

边界：示例不是现实税务规则；舍入方式需按具体业务规定补充。

## margin-sensitivity：商品毛利与零收入边界

输入：收入、成本同口径且币种一致。

| 操作目的 | 命令 | 参数例子 |
| --- | --- | --- |
| 1. 将真实业务记录按列结构写入；示例为可计算的测试输入 | `range.setValues` | `{"range":"A1","values":[["商品","收入","成本","毛利","毛利率"],["A",1000,650,"=B2-C2","=IF(B2=0,0,D2/B2)"],["B",0,20,"=B3-C3","=IF(B3=0,0,D3/B3)"]]}` |
| 2. 仅以百分比显示比率，不放大底层值 | `home.numberFormat` | `{"range":"E2:E3","format":"0.0%"}` |
| 3. 对金额列设显示格式，不把金额转成字符串 | `home.numberFormat` | `{"range":"B2:D3","format":"0.00"}` |
| 4. 检查公式与原始数据位置 | `sheet.read` | `{"range":"A1:E3","formulas":true}` |
| 5. 读取未格式化计算值，按检查项核对结果及错误值 | `sheet.read` | `{"range":"A1:E3","formulas":false,"formatted":false}` |

检查：D2=350，E2=0.35；零收入行无除零错误；零收入行毛利仍为-20。

边界：把零收入率显示为0只是示例定义；真实报表可要求空值或特殊标记。
