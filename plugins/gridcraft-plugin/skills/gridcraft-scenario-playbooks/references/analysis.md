# GridCraft analysis 场景

默认从新建空文件执行。按实际输入替换示例，已有文件先定位目标；不要清空或全选已有文稿。组合演示场景只新建一次，后续跳过带newDocumentOnly标记的步骤。

## weighted-vendor-score：供应商多维加权评分

输入：评分口径一致，权重明确且总和为1。

| 操作目的 | 命令 | 参数例子 |
| --- | --- | --- |
| 1. 将真实业务记录按列结构写入；示例为可计算的测试输入 | `range.setValues` | `{"range":"A1","values":[["供应商","质量","交付","服务","加权分"],["A",90,80,70,"=B2*$B$5+C2*$C$5+D2*$D$5"],["B",80,95,90,"=B3*$B$5+C3*$C$5+D3*$D$5"],["权重和","=SUM(B5:D5)"],["权重",0.5,0.3,0.2]]}` |
| 2. 对金额列设显示格式，不把金额转成字符串 | `home.numberFormat` | `{"range":"E2:E3","format":"0.00"}` |
| 3. 检查公式与原始数据位置 | `sheet.read` | `{"range":"A1:E5","formulas":true}` |
| 4. 读取未格式化计算值，按检查项核对结果及错误值 | `sheet.read` | `{"range":"A1:E5","formulas":false,"formatted":false}` |

检查：B4=1；E2=83，E3=86.5；权重改变后两行公式仍引用绝对地址。

边界：评分必须来自可追溯评价；不要把合成数值作为实际供应商结论。

## sales-ranked-rows：销售额排行且整行保持对应

输入：每行是一名销售与对应金额，首行为表头。

| 操作目的 | 命令 | 参数例子 |
| --- | --- | --- |
| 1. 将真实业务记录按列结构写入；示例为可计算的测试输入 | `range.setValues` | `{"range":"A1","values":[["姓名","销售额","区域"],["甲",100,"东区"],["乙",250,"西区"],["丙",150,"南区"]]}` |
| 2. 对完整数据矩形按金额降序，表头不参与 | `data.sort` | `{"range":"A1:C4","header":true,"keys":[{"column":"B","order":"desc"}]}` |
| 3. 检查公式与原始数据位置 | `sheet.read` | `{"range":"A1:C4","formulas":true}` |
| 4. 读取未格式化计算值，按检查项核对结果及错误值 | `sheet.read` | `{"range":"A1:C4","formulas":false,"formatted":false}` |

检查：排序后首行乙/250/西区；金额与姓名和区域仍同一行；表头没有移动到数据区。

边界：同额排序不假设稳定，排名并列规则由业务确定。

## regional-sales-sum：销售区域汇总并建立图表

输入：区域名称已统一、金额列无混入文本；同币种同周期。

| 操作目的 | 命令 | 参数例子 |
| --- | --- | --- |
| 1. 将真实业务记录按列结构写入；示例为可计算的测试输入 | `range.setValues` | `{"range":"A1","values":[["区域","销售额",null,"区域汇总","金额"],["东区",100,null,"东区","=SUMIF(A2:A4,D2,B2:B4)"],["西区",80,null,"西区","=SUMIF(A2:A4,D3,B2:B4)"],["东区",50]]}` |
| 2. 使用汇总区域建立柱形图 | `insert.chart` | `{"range":"D1:E3","type":"column","title":"区域销售额（示例）","at":"G2"}` |
| 3. 检查公式与原始数据位置 | `sheet.read` | `{"range":"A1:E4","formulas":true}` |
| 4. 读取未格式化计算值，按检查项核对结果及错误值 | `sheet.read` | `{"range":"A1:E4","formulas":false,"formatted":false}` |

检查：E2=150，E3=80；图表引用汇总而非明细重复统计；标题标明期间与币种。

边界：未知区域不能被默默漏掉；真实数据需先列完整区域或用透视表。

## month-growth-guard：月度增长率与零基期处理

输入：月份已按时间顺序排列；0基期采用明确的示例规则。

| 操作目的 | 命令 | 参数例子 |
| --- | --- | --- |
| 1. 将真实业务记录按列结构写入；示例为可计算的测试输入 | `range.setValues` | `{"range":"A1","values":[["月份","金额","环比"],["2026-01",0,null],["2026-02",120,"=IF(B2=0,0,B3/B2-1)"],["2026-03",150,"=IF(B3=0,0,B4/B3-1)"]]}` |
| 2. 将增长率显示为百分比 | `home.numberFormat` | `{"range":"C3:C4","format":"0.0%"}` |
| 3. 检查公式与原始数据位置 | `sheet.read` | `{"range":"A1:C4","formulas":true}` |
| 4. 读取未格式化计算值，按检查项核对结果及错误值 | `sheet.read` | `{"range":"A1:C4","formulas":false,"formatted":false}` |

检查：C3=0，C4=0.25；第一期无伪造增长率；月份顺序没有按金额重排。

边界：零基期的0不是自然增长率；真实交付须标注为不可比或按业务定义处理。
