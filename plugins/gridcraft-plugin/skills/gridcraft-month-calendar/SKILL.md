# 可重算月历模板

1. 先确认年份、月份和周起始；本例选择周一，不能套用地区默认周日。展示相邻月份日期并使用mm-dd，避免将上月31日误读为本月。
2. DATE与WEEKDAY确定首个周一，其余41格引用同一锚点逐日增加。保留真实日期数值及日期格式，不把日期写成不可重算文本。
3. 只允许整数月份1至12，防止DATE把13月自动滚到下一年。闰年以实际日期函数结果和独立日期计算同时核对。
4. 周末列使用填色辅助辨认；此模板不等同地区节假日或排班规则。改变年月后重新读取42格，核对本月天数和首尾边界。

先读 [实际方法、参数与会话](references/craft-methods.md) 及 [完整参数模板](references/craft-steps.json)。输入和示例数值须按任务替换；已有工作簿先检查工作表及占用范围，选择本任务唯一新表名，不覆盖原表。

需要内嵌画面时交给 **gridcraft-editor** 技能。独立安装：`npx skills add full-aigc-skills/gridcraft-skills --skill gridcraft-editor`。本批为开发候选，尚未进入市场新版本。

42格逐日连续且首格为周一，2028年2月包含29日一次；改为2027年2月只有28日。月份13、缺失或非整数输入清空日期网格，不生成错误月份。

只处理1901至9999年Gregorian/Excel日期，周一起始，展示相邻月份日期；不假定地区节假日、调休或团队工作日。每个格子是日期公式，事项需放在独立区域，不覆盖公式。

另存可编辑XLSX并重开，修改输入验证重算。规则存在不代表所有API写入会执行输入拦截；必须核对计算结果和异常提示。外部Excel排版、真实业务内容与宿主同步分别验收。[固定GitHub来源与许可](references/workflow-sources.json)。
