# 场景技能候选

新增技能位于 skills/，独立技能源维护，插件本地候选按 scenario-candidates.json 校验。既有发布快照不变。当前完成内容与实际场景视觉验收分开；尚未逐场景完成用户素材验收。

- `gridcraft-clean-table`：表格清洗（重复、缺失和格式不一致的数据）
- `gridcraft-sales-summary`：销售汇总（按时间、商品或区域汇总销售）
- `gridcraft-budget-tracker`：预算执行表（预算、实际和差异管理）
- `gridcraft-reconcile-data`：两表对账（订单、账单与库存数据核对）
- `gridcraft-formula-audit`：公式检查（引用错误、硬编码与范围遗漏）
- `gridcraft-dashboard`：业务看板表（指标、图表和筛选展示）
