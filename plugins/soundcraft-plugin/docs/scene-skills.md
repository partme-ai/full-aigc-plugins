# 场景技能候选

新增技能位于 skills/，独立技能源维护，插件本地候选按 scenario-candidates.json 校验。既有发布快照不变。当前完成内容与实际场景视觉验收分开；尚未逐场景完成用户素材验收。

- `soundcraft-podcast-cleanup`：播客人声整理（口播剪辑、停顿和响度）
- `soundcraft-voice-over-mix`：配音与背景音乐混音（对白清晰度和背景音乐控制）
- `soundcraft-audio-edit`：音频片段剪辑（裁切、拼接和淡入淡出）
- `soundcraft-music-demo`：音乐小样整理（多轨平衡、声像和基本效果）
- `soundcraft-audio-delivery`：音频格式交付（采样率、位深与文件命名）
- `soundcraft-dialogue-leveling`：多人口播音量统一（多位说话人的响度和音色衔接）
