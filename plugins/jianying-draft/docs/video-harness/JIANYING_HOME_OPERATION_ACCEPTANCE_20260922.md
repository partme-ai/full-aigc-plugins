# 剪映主页功能黑盒验收记录（2026-09-22）

## 结论

本轮补验昨天未覆盖的剪映主页。运行环境为 macOS 剪映专业版
`11.6.0-beta2`，使用笔记本内置屏幕和真实账号会话；没有提交 AI 生成、上传、开票、邀请、
购买、账号变更或永久删除。

主页不能被建模为一个简单的“打开草稿”页面。它同时承担：

1. 本地草稿与文件夹管理；
2. 个人/小组云空间与即梦资产入口；
3. 多个独立 AI 创作工作台；
4. 订阅、团队、帮助、消息、设置、网络和版本治理。

因此生产实现需要把主页动作纳入 CLI Control Catalog，并由插件 Harness 对上传、费用、账号、
删除和升级分别设门禁。

## 版本漂移证据

版本窗口确认当前运行版本为 `11.6.0-beta2`。点击“检查更新”后，剪映自动下载了
`11.6.0 内测版 3`，并要求“立即重启”完成升级。本轮没有点击重启，因此当前运行进程仍是
`11.6.0-beta2`，但宿主已经存在待安装更新。

这证明生产 Canary 必须绑定精确剪映版本，并在验收期间关闭或隔离自动更新；否则重启后语义 ID、
页面布局和能力结果可能漂移。

## CLI 与插件职责映射

`jianying-cli` 应提供可审计的原子能力，例如：

- `home.inspect`、`home.workbench.list/open`；
- `draft.list/search/view/sort`、`draft.folder.create`、`draft.menu.inspect`、`draft.recycle_bin.inspect`；
- `cloud.personal.inspect`、`cloud.team.inspect`、`entitlement.inspect`；
- `settings.inspect`、`runtime.network_check`、`runtime.version.inspect`；
- 对上传、删除、账号、升级和费用动作返回结构化确认点，而不是直接执行。

`jianying-draft-plugin` 负责把这些原子能力编排进 Harness：先读取工作台要求和版型/权益，再校验素材、
上传目的地、预算和版本 Canary，最后才允许生成、导入、上传或恢复。
