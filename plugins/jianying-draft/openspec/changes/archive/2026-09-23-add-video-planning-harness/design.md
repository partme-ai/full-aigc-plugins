## Context

沿用 proposal.md 与既有 Rust CLI 迁移规格。技能内容由技能仓单向发布，插件只消费锁定副本。用户已要求直接实施并交付 108 个独立网上实操 example。

## Goals / Non-Goals

目标：场景目录、真实来源、方法与能力映射、可验证路由。非目标：此次不补齐真实原生导出或声称 108 条剪辑已实机通过。

## Decisions

- 技能 references 下的结构化场景与 Recipe 是内容唯一源，108 个 example 为逐场景可读文件；来源只短摘要不复制文章或媒体。
- 插件持有 Schema、路由器和执行入口；规划数据经技能锁消费。未发布候选只允许显式开发输入，不改正式锁来假冒已发布。
- 先做确定性 ID/关键词候选与显式选型；低置信度返回待选择，不将关键词匹配包装为视觉理解。
- 必需能力分交付等级，结构草稿不强依赖 native；语义理解、节拍、多机位、事实核查单独标明人工或外部能力。
- 对 108 项分别检索与选择来源，热度证据不足保留未知。逐场景至少有独特素材要求、故事段落、剪辑取舍和验收点。

## Risks / Trade-offs

- [搜索摘要有限] → 记录阅读范围，访问具体页面并保留失败/未观看边界。
- [模板同质化] → 场景特有步骤与成片结构独立编写，共用只限通用 CLI 调用约束。
- [插件发布仍有原生门禁] → 本地测试/候选与 immutable 正式同步分开记录，保留发布阻塞。

## Migration Plan

增加规划技能与内容校验；更新技能元数据并生成候选 manifest；插件增加可测试的规划入口；通过后发布技能并由插件锁定消费，最终发布仍满足现有门禁。回滚使用前版技能和插件锁。
