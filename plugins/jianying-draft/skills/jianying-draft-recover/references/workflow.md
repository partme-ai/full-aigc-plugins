# 恢复决策参考

## 状态处理

| 状态 | 动作 |
|---|---|
| queued | 检查是否仍需执行，可安全取消 |
| running | 先确认执行器是否仍存活，不重复启动 |
| failed | 修复确定原因，新批准后显式 retry |
| ambiguous | 对账远端/原生制品，禁止自动重提 |
| succeeded | 验证制品哈希；漂移时 fail closed |

## 草稿恢复

- 快照必须是同一事务记录的完整、已验证副本。
- 恢复写入前关闭相关编辑器，并核对目标路径。
- 原草稿和恢复目标不得通过模糊 glob 选择。
- 恢复完成后运行结构验证；不能仅凭复制命令成功结案。

## 素材重链

只在候选路径唯一、类型匹配且内容身份可解释时提交。多个同名素材属于歧义，交给用户选择。
