# 动效工作流参考

## 建模原则

- 时间点使用段内相对微秒，并由 FrameRate 生成量化报告。
- 平移时预留缩放余量，避免画布边缘暴露。
- 变速同时验证 source range、目标 duration 和音高策略。
- 入场/出场/循环动画与属性关键帧是不同能力，不互相假定可替代。

## Capability 停止路径

当前 manifest 若把 keyframe、animation 或 quantization 标为 partial，只能生成计划并报告缺口，不能执行后宣称完整支持。

## 验收

结构层检查关键帧顺序、边界和引用；冷重开检查可解析；播放检查运动节奏、插值、露边和转场冲突。
