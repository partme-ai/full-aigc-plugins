# 错误与恢复：转场目录、边界与播放验收

| 状态 | 处理 | 禁止 |
|---|---|---|
| capability 缺失或 partial | 停止受影响步骤，列出最低能力与替代只读路径 | 猜测支持、切换未声明引擎 |
| 输入/schema 无效 | 返回字段级错误，保留计划供修正 | 丢弃上下文、自由补字段 |
| 明确失败 | 修复输入后请求新批准，再显式 retry | 沿用旧批准 |
| ambiguous/超时 | 查询 task、审计和外部制品，保持阻塞 | 自动重提付费或原生动作 |
| 验证失败 | 保留隔离副本和日志，回到最近检查点 | 覆盖源草稿、删除证据 |
