# 多镜头曝光与白平衡匹配

## 数据流

```text
代理帧与镜头边界
→ 曝光/白平衡分析建议
→ 人工确认参考镜头与例外镜头
→ 绝对参数计划
→ 版本绑定 Runtime Control
→ 参数 readback
→ 前后画面与播放验证
```

## 规则

- 分析 Provider 只输出建议、置信度、代理帧摘要和适用镜头，不直接写草稿。
- 先选参考镜头，再比较亮度分布、白平衡、肤色和高光/阴影；不能只追求统一直方图。
- 写入必须使用绝对参数、精确版本语义 ID 和 readback；只有相对拖动时保持阻断。
- 室内外、舞台灯、日落、故意剪影和品牌色镜头默认列为人工例外。
- 滤镜不能冒充调节，模型建议不能冒充最终参数，代理帧通过不能冒充真实播放。

## 证据

至少保存应用前后参数、参考/例外列表、代理帧摘要、Provider identity 和 readback。最终播放检查曝光跳变、肤色、闪烁和创作意图；远程分析需对上传文件、费用、保留期和 request-id 精确批准。
