# 标志开场动效


执行具体方法前读取 [Craft 场景命令与参数](references/craft-methods.md)，按其中的对象选择、会话、输入替换和结果检查执行。

## 任务起点

先读取素材，确认交付用途、目标尺寸或时长、修改范围与必要格式。能从任务和素材确定的细节直接采用合理默认值；只询问会改变结果的缺失条件。

需要可见编辑器时交给 **effectcraft-editor** 技能。独立安装：`npx skills add full-aigc-skills/effectcraft-skills --skill effectcraft-editor`。当前新增技能为本地候选，发布前使用本地配套插件，不把此安装命令当作已发布证明。

## 执行步骤

1. 确认时长、画幅和透明背景需求，导入矢量或高分辨率标志。
2. 建立合成与安全区，用位置、缩放或透明度设计主动作。
3. 调整关键帧缓动，给标志留足可读停留时间。
4. 逐帧检查开始、峰值与结束，输出预览和目标格式。

## 工具落地

使用 command_list 读取当前 Web 引擎命令；command_run 的 id 和 params 对应实际 execute 接口；inspect 检查画面，save_project 保存新工程路径，save_file 取回已生成虚拟文件。

先读取实际工具 schema，再填写参数；对象或文档 ID 使用返回值。查询到的命令必须在当前后端可用。保存前选择新输出路径，保留输入。需要的算法、格式或命令不存在时说明缺口，不能用相近名称冒充。

## 结果检查

- 标志比例不变，运动不突兀。
- 透明背景需求实际保留 alpha。
- 工程含可编辑图层与关键帧。

对照用户目标检查实际内容，而不只检查进程退出码。局部编辑查看局部细节，版式任务查看整页，时间媒体查看起止与关键段。异常结果先检查当前工程，避免重复执行不可逆操作。

## 交付

返回可编辑工程、实际派生文件和简短说明：做了哪些修改、哪些步骤因当前能力未执行、需要用户判断的内容。只列真实存在且已经检查的文件。若用户随后返工，读取本次源工程并局部修改，保留已接受的内容。
